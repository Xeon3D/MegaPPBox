* Android: MegaPPBox now runs on Android phones and tablets (64-bit ARM, Android 9 or later), and every release includes the APK. It has touch, sound, Mega-Link over Wi-Fi (on by default, link name `megatouch`) and the modem. It needs a fast device: it runs at full speed on a Galaxy S25 Ultra.

* Security keys are no longer included. Import dumps of your own keys with **Import key…** in the Machine Manager (or the Key menu). MegaPPBox reads which release a dump is for from the dump itself, and the Machine Manager then fits it to every image of that release.

* Keys…: a key manager that lists the installed keys with the releases each one runs, and imports or deletes them.

* Machine Manager: **Import images…** copies disk and CD images into your images folder.

* Upgrading from 1.06 or earlier: those versions had keys built in, and this one has none. Import your key dumps before running your images.
