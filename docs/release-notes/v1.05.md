* Touch: taps no longer go missing on the Linux MAXX releases (Crown, Jade, Ruby, Sapphire…). The touch controller could lose the byte that says the finger lifted, so a quick tap after another turned into a drag and was ignored.

* Touch: very quick taps (a touchpad tap, a fast click) always register.

* Touch: Ruby 2 V11.00 takes touch.

* Touch: the 3M MicroTouch controller now does everything in 3M's reference guide:
  * data formats Binary, Binary Stream, Zone, Raw and Calibrate Raw, besides Tablet, Decimal and Hexadecimal;
  * Mode Point and Mode Down/Up in every format, Mode Polled and Mode Status;
  * Calibrate New, Extended and Interactive, answering as the real controller does;
  * the settings commands (Parameter Lock, Parameter Set, Sensitivity, Filter, AutoBaud, Frequency Adjust, Restore Defaults), kept in the controller's memory;
  * Output Status and Unit Type report reset and power-on the way the hardware does.

* Mega-Link: link cabinets on your network, as the real ones did (Tools > Network settings…, per image; Local Switch or Remote Switch). Each image keeps its own card MAC.

* Network card for the DOS MAXX releases: a TRENDnet TE-16XP (MAXX 2K's card) at 0x340. The Linux MAXX releases keep their RTL8139.

* One network card per cabinet, set up in the Network dialog.

* Local switch: frames no longer arrive several times on PCs with many network adapters.
