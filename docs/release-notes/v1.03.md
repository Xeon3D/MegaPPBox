* Modem on COM2: an ActionTec 56K modem, as fitted by the MAXX TournaMAXX/MegaNET kits. Turned on per image, off by default.

* The modem can dial a TCP host (Tools > Modem settings…), e.g. a [TournaMAXX-Revival](https://github.com/Xeon3D/TournaMAXX-Revival) server, which brings tournaments, rankings and updates back to the DOS MAXX releases.

* Tools > Sound > Modem sounds: hear the modem's speaker or not.

* Network card: an RTL8139 behind NAT for the Linux MAXX releases (Ruby onward). Turned on per image, off by default.

* PC Card slots on the MAXX I/O board, so fewer errors show at boot.

* The Machine Manager has Modem and Network options for each image.
